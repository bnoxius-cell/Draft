# Handoffs

Each person keeps their own file here, named after their GitHub username in lowercase (for example `handoffs/radri.md`). Only edit your own. Newest entry on top. Rewrite stale entries instead of stacking them.

Template:

```
## YYYY-MM-DD, <area>
- Done:
- In progress:
- Next:
- Tested / not tested:
- Questions or needs for the other person:
```
